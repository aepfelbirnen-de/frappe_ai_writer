### Token usage

- **AI Writer Settings → Usage** shows the tokens used today, this month and in total, each with an estimated cost.
- Prices per million input and output tokens are configurable (default: claude-haiku-5-5).
- **Track Usage per User** (off by default) adds a per-user table for the current month. Check the law in your country before enabling it, for example on data protection and employee co-determination.
- Only token counts are stored, never the text. The full log is available as **AI Writer Usage** in the AI Writer workspace (managers only).
