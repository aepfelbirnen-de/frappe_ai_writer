### Cover letter formats

- The cover letter preview has a **Format** choice: **Letter** (salutation and paragraphs) or **Structured** (title as subject, short sections for starting point, services and benefits). Switching it writes the letter again in the new format.
- **AI Writer Settings → Cover Letter Format** sets the default format.
- The cover letter prompt now only holds the rules shared by both formats; an unchanged prompt from the previous version was updated automatically.
